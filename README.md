# 🎮 Pedra, Papel, Tesoura, Lagarto e Spock

Jogo interativo desenvolvido com **HTML, CSS e JavaScript**, baseado no clássico Pedra, Papel e Tesoura, com as opções extras **Lagarto** e **Spock**.

## ✨ Funcionalidades

- Escolha entre Pedra, Papel, Tesoura, Lagarto e Spock
- Sistema de pontuação
- Jogada automática do computador
- Resultado em tempo real
- Botão de jogar novamente
- Tela com regras do jogo

## 🛠️ Tecnologias

- HTML
- CSS3
- JavaScript

## 🚀 Como executar

1. Clone o link do repositório.
2. Abra o arquivo:

```bash
index.html
```

Ou utilize o **Live Server** no VS Code.

## 🎯 Regras

- Pedra vence Tesoura e Lagarto
- Papel vence Pedra e Spock
- Tesoura vence Papel e Lagarto
- Lagarto vence Papel e Spock
- Spock vence Pedra e Tesoura
